# Changelog

## 0.1.0 — October 10, 2026

Sleeve's first open-source release. [Try the hosted app](https://liner-c7u.pages.dev/) or [explore the synthetic demo](https://liner-c7u.pages.dev/#/demo).

- Local listening records from Last.fm history and Spotify ZIPs, with saved import checkpoints.
- Overview, artist/track/album rankings, timelines, eras, year reviews, taste changes, listening clocks and detailed record pages.
- Discover with catalogue-checked starting records, listening connections, a personal shelf and reversible feedback.
- Automatic preparation with independent artist, writing and recommendation statuses, early exploration and bounded recovery.
- Optional OpenRouter writing grounded in calculated summaries, with fixed model routes, output checks, caching and a shared public request budget. Calculated findings work independently.
- Bold themes, browser-local profiles, counting controls, exclusions and an offline app shell.
- MIT source, contribution/security guidance and Cloudflare self-hosting documentation. Release checks run on Windows and Linux with Node.js 22 and 24.

### Current limits

Direct Spotify requires a listener's own developer app. A new Last.fm account has no earlier listening history. Audio-feature coverage depends on existing analyses and is limited for newer releases. AOTY/RYM scores are not imported. AI interpretation can be unavailable or imperfect; data policies and known model limits are documented.
